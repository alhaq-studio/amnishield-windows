# AmnShield Roadmap

**Vision:** Empower Muslims worldwide to maintain digital purity and protect their families from harmful content through intelligent, privacy-respecting technology.

---

## 🚀 Version History

### v0.1.0 - Experimental Release (Current)
**Released:** November 9, 2025  
**Status:** Experimental / Alpha Testing

**Features:**
- ✅ Windows desktop application with system tray integration
- ✅ Browser extensions (Chrome, Firefox)
- ✅ AI-powered content analysis (offline)
- ✅ Application blocking for Windows programs
- ✅ Guardian password protection
- ✅ Desktop app ↔ extension communication via HTTP API
- ✅ Islamic-themed UI with Arabic typography
- ✅ Auto-start on Windows boot

**Known Limitations:**
- No automatic updates
- No password recovery mechanism
- Admin users can disable protection
- Browser-only protection (no network-level blocking)
- AI model ~85-90% accuracy
